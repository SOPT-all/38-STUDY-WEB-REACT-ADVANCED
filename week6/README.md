# 38-STUDY-WEB-REACT

LET'S SOPT 38기 웹 리액트 스터디입니다!

## 🏡 스터디 진행 방식

**📌 아티클 작성**

- 모든 스터디원은 해당 주차에 맞는 아티클을 작성해요.
- 아티클은 스터디 팀 블로그에 작성하여, 한번에 관리해요.

**📌 실습 준비**

- 실습이 있는 주차의 발표자는 실습을 준비해요.
- 해당 주차와 관련이 있다면, 모든 실습은 자유롭게 진행해주세요.
- 스터디 2일 전까지 PR을 작성하고, 스터디원과 함께 공유해요.

**📌 발표**

- 매주 2명씩 아티클 기반으로 발표를 진행해요.

**📌 리뷰**

- 매주 정해지는 조원들의 아티클을 읽고, 자신의 생각을 스터디 시간에 공유해요.
- 실습 PR에는 스터디 시작 전까지 코멘트를 달아주세요.

## 🚀 PR & 브랜치 규칙

### 📌 브랜치명

- 형식: `week{n}-{이름}`  
- 예시: `week1-jinseok`, `week3-seungtaek`  
- 각 주차별 실습은 자신의 브랜치에서 진행합니다.

### 📌 PR 제목

- 형식: `[Week {n}] {간단 실습 제목}`  
- 예시: `[Week 2] useState 직접 구현 `

### 📌 PR 내용

- 학습 내용 요약  
- 실습 파일 설명  
- 느낀 점 및 피드백 요청 사항 포함
